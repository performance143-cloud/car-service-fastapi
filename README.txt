# 🚗 АвтоБосс — Бэкенд Автосервиса (FastAPI + PostgreSQL)

Бэкенд полностью готов к интеграции с фронтендом. База данных нормализована, настроена электронная очередь и автоматическое распределение боксов. Настроен CORS (доступ открыт для всех локальных адресов фронта).

## 🚀 Как запустить проект у себя на компьютере:

1. **Клонируй репозиторий и перейди в папку проекта:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd car-service-fastapi
   ```

2. **Установи все необходимые библиотеки одной командой:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройка Базы Данных:**
   Убедись, что у тебя запущен PostgreSQL (наш бэкенд стучится на порт `5433` в базу `autoboss_db` с паролем `admin`). Таблицы создадутся автоматически при первом запуске бэкенда.

4. **Запуск сервера:**
   В терминале PyCharm введи команду:
   ```bash
   uvicorn main:app --reload
   ```

## 📝 Интерактивная документация (Swagger)
После запуска бэкенда перейди по ссылке:
👉 **http://127.0.0**

Здесь ты найдешь все готовые эндпоинты для фронтенда:
* `/auth/register` — Регистрация клиента (1:1 профиль в БД)
* `/auth/login` — Вход (возвращает JWT Access Token)
* `/cars` — Добавление и получение автомобилей клиента
* `/services` — Прайс-лист услуг для вывода на сайт
* `/appointments` — Онлайн-запись (сама считает электронную очередь и проверяет занятость боксов)
* `/queue` — Вывод активной очереди на текущий день для табло автосервиса
* `/appointments/{id}/status` — Обновление статуса ремонта мастером (ожидает / в работе / готова)
